# EduConnect Pakistan

This is the official repository for EduConnect Pakistan — a MERN stack platform that connects students with qualified tutors.

## 🔗 GitHub Repo
https://github.com/AbbasHafeez/educonnect-pakistan

## 🎓 Key Features
- Tutor Search & Filtering
- Session Booking & Management
- Review & Rating System
- Wishlist for Tutors
- Tutor Profile Management
- Earnings Tracking
- Admin Dashboard for Verification and Reporting

## 🛠️ Tech Stack
- MongoDB
- Express.js
- React.js
- Node.js

## 🚀 Setup Instructions
1. Clone this repo
2. Run `npm install` in both `client` and `server`
3. Configure your `.env` file
4. Run using `npm start`
